# android-payments
카드 추가 뷰를 구현한다

카드 번호, 만료일, 카드 소유자 이름, 비밀번호를 입력받는다

# 기능 목록

## 카드 추가 화면
- [x] 카드 추가 화면에 접속했을 때 카드사를 선택하는 바텀시트가 노출된다
  - [x] 카드사를 선택할 때 적절한 카드사 아이콘을 노출한다
  - [x] 선택한 카드사에 따라 카드 미리 보기가 바뀐다
- [x] 완료 버튼을 누르면 카드 목록 화면으로 넘어간다
- [x] 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출된다.

### 비밀번호
- [x] 비밀번호는 노출되어서는 안 된다

### 카드 번호
- [x] 카드 번호와 만료일의 경우 입력할 때 자동으로 기호(-, /)가 삽입된다

### 카드 소유자 이름
- [x] 카드 소유자 이름의 경우 입력 글자 제한이 30자이다

## 카드 목록 화면
- [x] 카드 목록이 보인다
- [x] 카드 목록이 비어 있을 때는 **"새로운 카드를 등록해 주세요"** 안내가 노출된다
- [x] 카드 목록에 카드가 한 개 있을 때에는 `카드 추가 버튼`이 하단에 노출된다
- [x] 카드 목록에 카드가 여러 개 있을 때에는 상단바에 `카드 추가 UI`가 노출된다
- [x] 카드 목록에서 카드를 선택하면 카드 수정 화면으로 이동한다

## 카드 수정 화면
- [x] 변경 사항이 발생하지 않으면 수정이 불가능하다
