# android-payments
결제할 때 사용할 지불 카드 관리 앱

## step1 (카드 추가 뷰)
- 카드 추가 뷰 상단에는 카드 추가 타이틀, 왼쪽엔 뒤로가기 버튼, 오른쪽엔 +(카드 추가) 버튼이 있다.
  - [ ] + 버튼을 누르면 카드가 추가 됐다는 토스트 메시지가 뜬다.
  
- [x] 카드 모양이 보인다.

- [x] 등록할 카드 번호를 입력할 수 있다.
  - [x] 입력할 때 자동으로 기호(-)가 삽입된다 (선택)
  
- [x] 등록할 카드 만료일을 입력할 수 있다.
  - [x] 입력할 때 자동으로 기호(/)가 삽입된다. (선택)
  
- [x] 등록할 카드 소유자 이름을 입력할 수 있다.
  - 카드 소유자 이름은 선택적으로 입력할 수 있다. 
  - [x] 카드 소유자 이름은 입력 글자 제한이 30자이다. (선택)
  
- [x] 등록할 카드 비밀번호 4글자를 입력할 수 있다.
  - [x] 비밀번호는 노출되어서는 안 되기에 별첨자로 뜨도록 한다.
