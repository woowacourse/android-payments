# 🚀 Compose 페이먼츠

## 1단계 - 카드 추가

### 기능 요구 사항
- 카드 추가 뷰를 구현한다.
- 비밀번호는 노출되어서는 안 된다.
- (선택사항) 각 입력 항목별 유효성 검사를 진행한다.
  - 카드 번호와 만료일의 경우 입력할 때 자동으로 기호(-, /)가 삽입된다.
  - 카드 소유자 이름의 경우 입력 글자 제한이 30자이다.

### 기능 목록
- 카드 추가
  - [ ] 카드 번호는 16자리 숫자이다.
  - [ ] 만료일은 월(MM)과 년도(YY) 각각 2자리 숫자이다.
  - [ ] 비밀번호는 4자리 숫자이다.
  - [ ] 비밀번호는 노출되지 않는다.
