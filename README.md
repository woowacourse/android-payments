# android-payments
결제할 때 사용할 지불 카드 관리 앱

## step1 (카드 추가 뷰)
- 카드 추가 뷰 상단에는 카드 추가 타이틀, 왼쪽엔 뒤로가기 버튼, 오른쪽엔 +(카드 추가) 버튼이 있다.
  
- [x] 카드 모양이 보인다.

- [x] 등록할 카드 번호를 입력할 수 있다.
  - [x] 입력할 때 자동으로 기호(-)가 삽입된다 (선택)
  
- [x] 등록할 카드 만료일을 입력할 수 있다.
  - [x] 입력할 때 자동으로 기호(/)가 삽입된다. (선택)
  
- [x] 등록할 카드 소유자 이름을 입력할 수 있다.
  - 카드 소유자 이름은 선택적으로 입력할 수 있다. 
  - [x] 카드 소유자 이름은 입력 글자 제한이 30자이다. (선택)
  
- [x] 등록할 카드 비밀번호 4글자를 입력할 수 있다.
  - [x] 비밀번호는 노출되어서는 안 되기에 별첨자로 뜨도록 한다.

## step2 (카드 목록 뷰)
- [x] 카드 홈 화면에 Payments 라는 타이틀이 보인다.
- [x] 카드 목록이 비어있을 때에는 "새로운 카드를 등록해주세요" 안내가 노출된다.
- [x] 카드 목록에 카드가 한 개 있을 때의 카드 추가 UI는 목록 하단에 노출된다.
- [x] 등록된 카드들이 노출된다.
  - [ ] 카드번호 뒷 8자리는 가려진 채로 노출된다.
- [x] 카드 목록에 카드가 여러 개 있을 때의 카드 추가 UI는 상단바에 노출된다.
- [x] 카드 추가 뷰에서 뒤로가기를 누르면 홈 화면으로 이동한다.
- [ ] 카드 추가 뷰에서 v(체크) 버튼을 누르면 카드가 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출되며 홈 화면으로 이동한다.
- [ ] 카드 추가 시 홈 화면에 바로 추가된 카드가 보인다.
