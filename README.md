# 💳 Compose 페이먼츠

## 📱️ 기능 요구 사항

### 📌 카드 추가 화면
- 카드 번호, 만료일, 카드 소유자 이름, 비밀번호를 입력할 수 있습니다.
  - 카드 번호는 `0000 - 0000 - 0000 - 0000` 형식입니다.
  - 만료일은 `MM / YY` 형식입니다.
  - 비밀번호는 `0000` 형식이며, `*` 표시로 마스킹됩니다.
- 각 입력 항목별 유효성 검사를 진행합니다.
  - 카드 소유자 이름은 선택 항목이며, 나머지는 필수 항목입니다.
  - 카드 번호 입력 시 자동으로 `-` 기호가 삽입됩니다.
  - 만료일 입력 시 자동으로 `/` 기호가 삽입됩니다.
  - 카드 소유자 이름은 최대 30자까지 입력할 수 있습니다.

## 🛠️ 프로그래밍 요구 사항
- `OutlinedTextField`를 사용합니다.
