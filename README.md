# android-payments

## 1단계 구현할 기능 목록
- 상단 바
  - [x] 뒤로가기 버튼
  - [x] 타이틀 '카드 추가'
  - [x] 완료 버튼
- [x] 카드 이미지
- [x] 카드 번호
  - [x] (선택사항) 입력할 때 자동으로 기호(-, /)가 삽입
- [x] 만료일
  - [x] (선택사항) 입력할 때 자동으로 기호(-, /)가 삽입
- [x] 카드 소유 이름
  - [x] (선택사항) 입력 글자 30자 제한
- [x] 비밀번호
  - [x] 입력된 숫자가 보이지 않도록 마스킹(예: •) 처리

## 2단계 구현할 기능 목록
카드 목록 화면
- [x] 새로운 Activity에 카드 목록 화면 추가
- [x] 카드 추가 화면과 연결
- [x] 새로운 카드가 추가되었을 때 카드 목록 업데이트하는 기능 추가
- [x] 목록이 비어있을 때 "새로운 카드를 등록해주세요"라는 텍스트 안내 추가
- [x] 카드가 한 개 있을 때 카드 추가 UI를 목록 하단에 노출
- [x] 카드가 여러 개 있을 때 카드 추가 UI를 상단바에 노출
- [x] 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트 노출
- [x] 카드 목록이 노출될 때 Column 활용
- [x] 카드 목록 상태에 따른 변경사항을 UI 테스트 혹은 Preview로 확인

## 3단계 구현할 기능 목록
- [x] 카드사 도메인 추가
- [x] 카드 추가 화면에 접속했을 때 ModalBottomSheet 노출
- [x] ModalBottomSheet에서 카드사를 선택하는 기능
- [x] 카드사를 필수로 선택하는 기능
- [x] 선택한 카드사에 따라 카드사 이름이 카드에 보이는 기능
- [x] 선택한 카드사에 따라 카드의 색상이 변경되는 기능
- [x] (선택사항) 카드사를 선택할 때 적절한 카드사 아이콘을 노출
