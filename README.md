# 💳 Compose 페이먼츠

## 📱️ 기능 요구 사항

### 📌 카드 목록 화면

- 카드의 목록을 볼 수 있습니다.
- 카드가 하나도 없을 시 `새로운 카드를 등록해주세요` 문구가 표시됩니다.
- `+` 또는 `추가` 버튼을 눌러 카드 추가 화면으로 이동할 수 있습니다.
    - 카드가 한 개 이하일 때는 카드 목록 하단에 `+` 버튼을 표시합니다.
    - 카드개 두 개 이상일 때는 상단 바에 `추가` 버튼을 표시합니다.

### 📌 카드 추가 화면

- 카드 번호, 만료일, 카드 소유자 이름, 비밀번호를 입력할 수 있습니다.
    - 카드 번호는 숫자 16자 형식입니다.
    - 만료일은 `MM / YY` 형식입니다.
    - 비밀번호는 숫자 4자 형식이며, 마스킹됩니다.
- 각 입력 항목별 유효성 검사를 진행합니다.
    - 카드 소유자 이름은 선택 항목이며, 나머지는 필수 항목입니다.
    - 카드 번호 입력 시 숫자 4개마다 자동으로 ` - ` 기호가 삽입됩니다.
    - 만료일 입력 시 `MM`과 `YY` 사이에 자동으로 ` / ` 기호가 삽입됩니다.
    - 카드 소유자 이름은 최대 30자까지 입력할 수 있습니다.

## 🛠️ 프로그래밍 요구 사항

- `OutlinedTextField`를 사용합니다.
- 카드 목록에 `Column`을 사용합니다.
- 카드 목록 상태에 따른 UI 변경사항을 UI 테스트 또는 Preview로 검증합니다.
