# android-payments

## 구현할 기능 목록

### step1

- [x] 카드 추가 뷰를 구현한다.
    - [x] 비밀번호를 가린다.
- [ ] (선택사항) 각 입력 항목별 유효성 검사를 진행한다.
    - [ ] 카드 번호와 만료일의 경우 입력할 때 자동으로 기호(-, /)가 삽입된다.
    - [x] 카드 번호의 경우 글자 제한이 16자이다.
    - [x] 만료일의 경우 글자 제한이 4자이다.
    - [ ] 만료일의 숫자는 날짜로 변환이 가능하여야 한다.
    - [x] 카드 소유자 이름의 경우 입력 글자 제한이 30자이다.
    - [x] 비밀번호의 경우 글자 제한이 4자이다.
