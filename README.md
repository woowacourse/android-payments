# android-payments
---
## 1 단계 기능 요구 사항
-  추가하는 카드의 정보를 입력할 수 있음

**카드 추가 페이지**
- [x] 카드 번호 입력하는 text가 있다.
    - [x] 힌트의 모양은 0000 - 0000 - 0000 - 0000
    - [x] 카드 번호 입력창에는 숫자만 입력할 수 있다
    - [x] 4단위 다음에는 -가 자동으로 삽입된다
    - [x] 카드 번호 입력할 때 자동으로 기호(-)가 삽입된다.
- [x] 만료일 입력하는 text가 있다
    - [x] 힌트의 모양은 MM / YY 이다
    - [x] 만료일 입력창에는 숫자만 입력할 수 있다
    - [x] 만료일 입력할 때 자동으로 기호(/)가 삽입된다.
- [x] 카드 소유자의 이름(선택) 입력창이 있다
    - [x] 카드 소유자 이름 입력창의 힌트는 "카드에 표시된 이름을 입력하세요"이다
    - [x] 카드 소유자 이름은 1~30자 사이이다
    - [x] 카드 소유자 이름의 길이가 화면에 나온다
- [x] 비밀 번호 입력창이 있다
    - [x] 비밀 번호 힌트는 0000이다
    - [x] 비밀 번호 입력에는 숫자만 입력할 수 있다
    - [x] 입력한 비밀 번호의 모양은 *로 표시된다
    - [x] 비밀번호는 4자리이다

## 2 단계 기능 요구 사항
- [x] 카드 추가 화면과 연결
- [x] 새로운 카드가 추가되었을 때 카드 목록이 업데이트
- [x] 카드 목록이 비어있을 때 "새로운 카드를 등록해주세요" 안내가 노출
- [x] 카드 목록에 카드가 한 개 있을 때의 카드 추가 UI는 목록 하단에 노출
- [x] 카드 목록에 카드가 여러 개 있을 때의 카드 추가 UI는 상단바에 노출
- [x] 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출

## 3 단계 기능 요구 사항
- [x] (선택 사항) 카드사를 선택할 때 적절한 카드사 아이콘을 노출한다.
- [x] 카드 추가 화면에 접속했을 때 카드사를 필수로 선택해야 한다.
- [x] 모달 창 외의 화면을 누르면은 모달이 꺼지지 않는다.
- [x] 선택한 카드사에 따라 카드 미리보기가 바뀌어야 한다.
  - 카드 이름
  - 카드 색상

## 4단계 기능 요구사항
- [ ] 수정 기능 구현
  - [ ] 카드 목록에서 카드를 선택하면, 수정화면으로 이동
  - [ ] 카드 수정 화면에서 변경사항이 발생하지 않으면 수정이 불가능
  - [ ] 카드 목록 화면에서 수정된 카드를 볼 수 있음
