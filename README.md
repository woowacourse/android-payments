# android-payments

## 기능 구현 목록

### 카드 추가 화면
- [x] 카드 번호 입력 필드 구현
  - [x] 초기 상태 : 힌트로 "0000 - 0000 - 0000 - 0000" 표시
  - [x] 숫자만 입력 가능하도록 키보드 타입 설정
  - [x] 입력 시에, 4자리를 기준으로 하이픈(-) 자동 삽입
  - [x] 16자를 초과해 입력할 수 없음

- [x] 만료일 입력 필드 구현
  - [x] 초기 상태 : 힌트로 "MM/YY" 표시
  - [x] 숫자만 입력 가능하도록 키보드 타입 설정
  - [x] MM/YY 형식으로 자동 슬래시(/) 추가
  - [x] 4자를 초과해 입력할 수 없음

- [x] 카드 소유자 이름 입력 필드 구현
  - [x] 초기 상태 : 힌트로 "카드에 표시된 이름을 입력하세요" 표시
  - [x] 영문(대문자)으로만 입력 가능
  - [x] 30자를 초과해 입력할 수 없다.
  - [x] 하단에 현재 입력한 글자수 출력

- [x] 비밀번호 입력 필드 구현
  - [x] 초기 상태 : 힌트로 "0000" 표시
  - [x] 입력 내용이 보이지 않도록 마스킹 처리
  - [x] 4자를 초과해 입력할 수 없다

- [x] 유효성 검사 및 UI 상호작용
  - 필수 입력 필드(카드 번호, 만료일, 비밀번호)가 유효성 검사를 통과했을 때만 상단 확인 버튼 활성화

- [x] TopAppBar (상단 바) 구현
  - 뒤로 가기 버튼
  - 확인 버튼 (활성화/비활성화 상태 관리)

### 카드 목록 화면
- [x] 카드 목록 화면을 구현하여 카드 추가 화면과 연결한다.
- [x] 새로운 Activity로 구현한다.
- [x] 새로운 카드가 추가되었을 때 카드 목록이 업데이트 되어야 한다.
- [x] 카드 목록 상태에 따른 UI 변경사항을 노출한다.
- [x] 카드 목록이 비어있을 때에는 "새로운 카드를 등록해주세요" 안내가 노출되어야 한다.
- [x] 카드 목록에 카드가 한 개 있을 때의 카드 추가 UI는 목록 하단에 노출된다.
- [x] 카드 목록에 카드가 여러 개 있을 때의 카드 추가 UI는 상단바에 노출된다.
- [x] 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출된다.

- [x] 카드 추가 화면에 접속했을 때 카드사를 필수로 선택해야 한다.
- [x] 선택한 카드사에 따라 카드 미리보기가 바뀌어야 한다.
- [x] (선택사항) 카드사를 선택할 때 적절한 카드사 아이콘을 노출한다.
