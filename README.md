# android-payments
## 1단계 - 카드 추가
### 카드 번호 입력
- [x] 카드 번호 16자리를 입력한다.
- [x] 카드 번호 4자리마다 구분자가 추가된다.
- [x] 숫자가 아닌 값은 입력할 수 없다.

### 카드 만료일 입력
- [x] 카드 만료일 (월, 연도) 을 입력한다.
- [x] 월과 연도 사이에 구분자가 추가된다.
- [x] 숫자가 아닌 값은 입력할 수 없다.

### 카드 소유자 이름 입력
- [x] 카드 소유자 이름을 입력한다.
- [x] 카드 소유자 이름은 최대 30자이다.
- [x] 카드 소유자 이름의 길이가 출력된다.

### 카드 비밀번호 입력
- [x] 카드 비밀번호 4자리를 입력한다.
- [x] 입력한 비밀번호는 특수문자로 변환된다.
