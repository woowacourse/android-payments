# 🚀 Compose 페이먼츠

## 기능 요구 사항

### 1단계 - 카드 추가
- 카드 추가 뷰를 구현한다.
- 비밀번호는 노출되어서는 안 된다.
- (선택사항) 각 입력 항목별 유효성 검사를 진행한다.
  - 카드 번호와 만료일의 경우 입력할 때 자동으로 기호(-, /)가 삽입된다.
  - 카드 소유자 이름의 경우 입력 글자 제한이 30자이다.

### 2단계 - 카드 목록
- 카드 목록 화면을 구현하여 카드 추가 화면과 연결한다.
  - 새로운 Activity로 구현한다.
  - 새로운 카드가 추가되었을 때 카드 목록이 업데이트 되어야 한다.
- 카드 목록 상태에 따른 UI 변경사항을 노출한다.
  - 카드 목록이 비어있을 때에는 "새로운 카드를 등록해주세요" 안내가 노출되어야 한다.
  - 카드 목록에 카드가 한 개 있을 때의 카드 추가 UI는 목록 하단에 노출된다.
  - 카드 목록에 카드가 여러 개 있을 때의 카드 추가 UI는 상단바에 노출된다.
- 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출된다.

### 3단계 - 카드사 선택

- 카드 추가 화면에 접속했을 때 카드사를 필수로 선택해야 한다.
- 선택한 카드사에 따라 카드 미리보기가 바뀌어야 한다.
- (선택사항) 카드사를 선택할 때 적절한 카드사 아이콘을 노출한다.

## 기능 목록
- 카드 목록
  - [x] '추가' 버튼을 클릭하면 카드 추가 화면으로 이동한다.
  - [x] 카드 목록이 비어있을 때 "새로운 카드를 등록해주세요" 안내가 노출된다.
  - [x] 카드 목록에 카드가 한 개 있을 때 목록 하단에 카드 추가 UI가 노출된다.
  - [x] 카드 목록에 카드가 여러 개 있을 때 상단바에 카드 추가 UI가 노출된다.
  - [x] 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출된다.
  - [x] 새로운 카드가 추가되었을 때 카드 목록이 업데이트된다.

- 카드 추가
  - [x] 카드 번호는 16자리 숫자이다.
  - [x] 만료일은 월(MM)과 년도(YY) 각각 2자리 숫자이다.
  - [x] 비밀번호는 4자리 숫자이다.
  - [x] 비밀번호는 노출되지 않는다.
  - [x] 카드 소유자 이름은 최대 30자이다.
  - [x] '뒤로가기' 버튼을 클릭하면 카드 목록 화면으로 이동한다.
