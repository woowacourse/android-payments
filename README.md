# android-payments

## Step 1

- [x] 카드 추가 뷰를 구현한다.
    - [x] 카드_번호_입력_후_키보드의_다음_버튼을_누르면_만료일_입력창으로_넘어간다
    - [x] 만료일_입력_후_키보드의_다음_버튼을_누르면_카드_소유자_이름_입력창으로_넘어간다
    - [x] 카드_소유자_이름_입력_후_키보드의_다음_버튼을_누르면_비밀번호_입력창으로_넘어간다

### 카드 번호

- [x] 숫자가_아닌_값을_입력할_수_없다
- [x] 카드_번호의_경우_입력할_때_자동으로_기호가_삽입된다
- [x] 형식이_올바르지_않을_경우_에러_메시지를_출력한다

### 만료일

- [x] 만료일의_경우_입력할_때_자동으로_기호가_삽입된다
- [x] 4자리가_아닐_경우_에러_메시지를_출력한다
- [x] 만료_달이_올바르지_않을_경우_에러_메시지를_출력한다

### 카드 소유자 이름(선택)

- [x] 카드_소유자_이름의_경우_입력_글자_제한이_30자이다
- [x] 입력된_이름의_길이가_출력된다

### 비밀번호

- [x] 비밀번호는_노출되어서는_안_된다
- [x] 비밀번호는_4글자까지_입력할_수_있다
- [x] 형식이_올바르지_않을_경우_에러_메시지를_출력한다

## Step 2

- [ ] 카드 목록 화면을 구현한다.
    - [ ] 카드 추가 화면과 연결한다.
    - [ ] 새로운 카드가 추가되었을 때 카드 목록이 업데이트 되어야 한다.
    - [ ] 카드 목록 상태에 따른 UI 변경사항을 노출한다.
        - [ ] 카드 목록이 비어있을 때에는 "새로운 카드를 등록해주세요" 안내가 노출되어야 한다.
        - [ ] 카드 목록에 카드가 한 개 있을 때의 카드 추가 UI는 목록 하단에 노출된다.
        - [ ] 카드 목록에 카드가 여러 개 있을 때의 카드 추가 UI는 상단바에 노출된다.
    - [ ] 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출된다.
