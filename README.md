# android-payments
## 1단계 - 카드 추가
### 카드 번호 입력
- [x] 카드 번호 16자리를 입력한다.
- [x] 카드 번호 4자리마다 구분자가 추가된다.
- [x] 숫자가 아닌 값은 입력할 수 없다.

### 카드 만료일 입력
- [x] 카드 만료일 (월, 연도) 을 입력한다.
- [x] 월과 연도 사이에 구분자가 추가된다.
- [x] 숫자가 아닌 값은 입력할 수 없다.

### 카드 소유자 이름 입력
- [x] 카드 소유자 이름을 입력한다.
- [x] 카드 소유자 이름은 최대 30자이다.
- [x] 카드 소유자 이름의 길이가 출력된다.

### 카드 비밀번호 입력
- [x] 카드 비밀번호 4자리를 입력한다.
- [x] 입력한 비밀번호는 특수문자로 변환된다.

## 2단계 - 카드 목록
### 카드 목록 화면
- [x] 카드가 없을 경우 안내 텍스트와 카드 형태의 추가 버튼이 나타난다.
- [x] 카드가 1장만 존재할 경우 카드와 카드 형태의 추가 버튼이 나타난다.
- [x] 카드가 2장 이상인 경우 카드와 상단바에 추가 버튼이 나타난다.
- [x] `Column`으로 카드 목록을 출력한다.

### 카드 추가
- [x] 추가 버튼을 누르면 기존의 카드 추가 화면으로 이동한다.
- [x] 추가 완료 버튼을 누르면 목록 화면으로 이동한다.
- [x] 추가된 카드가 화면에 나타난다.
- [x] 추가가 완료되었다는 것을 토스트를 통해 알린다.

## 3단계 - 카드사 선택
### 카드사 선택
- [x] 카드 추가 화면 이동 시 카드사를 선택할 수 있다.
- [x] 선택한 카드사에 따라 카드의 UI가 변경된다.
- [x] `FlowRow`와 `ModalBottomSheet`를 활용하여 카드사 선택 UI를 구현한다.

## 4단계 - 카드 수정
### 카드 수정 화면
- [x] 카드 목록에서 카드를 클릭하면 수정 화면으로 이동한다.
- [x] 카드 수정 화면에서 변경사항이 발생하지 않았으면 수정할 수 없다.
- [x] 카드가 수정되면 카드 목록 화면에 변경사항이 반영된다.
