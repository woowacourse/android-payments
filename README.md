## 기능 요구 사항

### 카드 추가 화면

- [x] 필수 항목이 모두 유효할 때 확인 버튼이 활성화된다

#### 카드 이미지

- [x] 카드 이미지가 표시되어야 한다

#### 카드 번호

- [x] 카드 번호는 16자리이다
- [x] 카드 번호는 숫자만 입력 가능해야 한다
- [x] 카드 번호 4자리마다 구분 기호(-)가 자동 삽입된다
- [x] 4자리가 아닐 경우 구분 기호(-)가 제거된다
- [x] 카드 번호 Place Holder가 표시된다
    - 0000 - 0000 - 0000 - 0000

#### 만료일

- [x] 만료일은 MM / YY 형식으로 표시된다
- [x] 만료일은 숫자만 입력 가능해야 한다
- [x] 월(MM)은 1~12 사이여야 한다
- [x] 년도(YY)는 현재 연도 뒤 2자리부터 99까지 가능해야 한다
- [x] 해당 년도인 경우 현재 월 이후만 입력 가능해야 한다
- [x] 2자리마다 구분 기호(/)가 자동 삽입된다
- [x] 2자리가 아닐 경우 구분 기호(/)가 제거된다
- [x] 만료일 Place Holder가 표시된다
    - MM / YY

#### 카드 소유자 이름

- [x] 영문만 입력 가능하다
- [x] 입력 글자는 최대 30자이다
- [x] 현재 입력된 텍스트 길이가 표시되어야 한다
- [x] 이름 Place Holder가 표시된다
    - 카드에 표시된 이름을 입력하세요

#### 비밀번호

- [x] 비밀번호는 숫자만 입력 가능해야 한다
- [x] 입력한 비밀번호는 블라인드 처리되어야 한다
    - 예: ••••
- [x] 비밀번호 Place Holder가 표시된다
    - 0000
