# android-payments
카드 추가 뷰를 구현한다

카드 번호, 만료일, 카드 소유자 이름, 비밀번호를 입력받는다

# 기능 목록

## 카드 추가 화면
- [ ] 완료 버튼을 누르면 카드 목록 화면으로 넘어간다
- [ ] 새로운 카드를 추가하면 "카드가 추가되었습니다" 토스트가 노출된다.

### 비밀번호
- [x] 비밀번호는 노출되어서는 안 된다

### 카드 번호
- [x] 카드 번호와 만료일의 경우 입력할 때 자동으로 기호(-, /)가 삽입된다

### 카드 소유자 이름
- [x] 카드 소유자 이름의 경우 입력 글자 제한이 30자이다


## 카드 목록 화면
- [ ] 카드 목록이 보인다
- [ ] 카드 목록이 비어 있을 때는 **"새로운 카드를 등록해 주세요"** 안내가 노출된다
- [ ] 카드 목록에 카드가 한 개 있을 때에는 `카드 추가 버튼`이 하단에 노출된다
- [ ] 카드 목록에 카드가 여러 개 있을 때에는 상단바에 `카드 추가 UI`가 노출된다
